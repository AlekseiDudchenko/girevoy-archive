# Знаки спортивных разрядов

Сюда кладутся изображения официальных знаков отличия ЕВСК. Имя файла — код разряда
из справочника `sport_ranks`:

| Файл | Знак |
| :- | :- |
| `zms.svg`  | Заслуженный мастер спорта |
| `msmk.svg` | Мастер спорта международного класса |
| `ms.svg`   | Мастер спорта |
| `kms.svg`  | Кандидат в мастера спорта |
| `i.svg`, `ii.svg`, `iii.svg` | I, II, III разряд |

Требования: квадрат, прозрачный фон, читается при 24 px (в таблице) и 35 px
(у заголовка страницы спортсмена), различим и на светлом, и на тёмном фоне.
PNG тоже подойдёт — тогда в `links` в `src/render.js` поменять расширение.

Положив файл, добавить его код в `RANK_ICONS` в `src/render.js`: рендер общий
для Worker и статического снимка, а Worker файловую систему не видит и сам
наличие файла не проверит. Кода нет в списке — показывается текстовый значок.

Изображения должны быть пригодны к публикации: официальные знаки берутся из
документов Минспорта, а не из случайных картинок в поиске.
