# Значки спортивных разрядов

Иконки для значка разряда на странице спортсмена. Имя файла — код разряда из
справочника `sport_ranks`, список кодов с иконками продублирован в `RANK_ICONS`
в `src/render.js`: рендер общий для Worker и снимка, а Worker файловую систему
не видит и наличие файла сам не проверит. Кода нет в списке — значок остаётся
текстовым.

**Знаки здесь условные.** Это не воспроизведение нагрудных знаков ЕВСК, а
оформление архива: лычки — разряды (одна у III, три у I), звезда — мастерские
звания (контурная у КМС, сплошная у МС, в кольце у МСМК, в двух кольцах у ЗМС).
Поэтому рядом с иконкой всегда остаётся подпись — по ней разряд и читается.
Появятся официальные изображения из документов Минспорта — файлы заменяются,
код менять не нужно.

| Файл | Разряд |
| :- | :- |
| `zms.svg`  | Заслуженный мастер спорта |
| `msmk.svg` | Мастер спорта международного класса |
| `ms.svg`   | Мастер спорта |
| `kms.svg`  | Кандидат в мастера спорта |
| `i.svg`, `ii.svg`, `iii.svg` | I, II, III разряд |

Требования к файлу: квадратный `viewBox`, прозрачный фон, читается при 24 px
(в таблице выступлений) и при 35 px (у заголовка страницы). Цвет задаётся внутри
SVG: как `<img>` иконка не видит токены страницы, поэтому тёмная тема — своим
`@media (prefers-color-scheme: dark)` в самом файле.
