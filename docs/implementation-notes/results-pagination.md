# Пагинация страницы «Все результаты»

Текущий production остаётся статическим на Cloudflare Pages.

Для `results.html` после рендера выполняется статический post-processing:

- в `<tbody>` остаются только первые 100 строк;
- полный набор результатов сериализуется в JSON внутри страницы;
- фильтрация и сортировка выполняются по этому массиву;
- в DOM одновременно находятся только строки текущей страницы;
- переход между страницами не требует сетевых запросов;
- при переходе production на Workers + D1 эту клиентскую реализацию нужно заменить серверными `WHERE / ORDER BY / LIMIT` согласно `docs/roadmap.md`.

Такой вариант уменьшает стоимость HTML/DOM parsing и дальнейших сортировок без изменения текущей статической архитектуры deployment.
