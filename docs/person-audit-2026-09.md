# Аудит дублей спортсменов

Прогон по правилам `.claude/skills/person-audit`. База — полная сборка
`scripts/build-static.sh` (40 турниров, 2019–2026), а не `npm run db:local`:
последний собирает только 11 протоколов и для аудита непригоден.

Всего записей спортсменов: **1834**, из них уже слито: **68**, активных: **1766**.
Кандидатов на дубли: **105 групп / 215 записей** — около 12 % активных записей.
(Четыре записи попадают сразу в два раздела: `#348`, `#787`, `#1052`, `#1210`.)

Ничего не слито. Ниже только классификация и основания; merge выполняется через
`data/merges.json` по решению администратора.

## Как искали

1. точное совпадение ФИО + год рождения — **0** (ключ склейки `gen_seed.py` их и так схлопывает);
2. совпадение ФИО при разном годе рождения;
3. совпадение фамилии, имени и года при разном или отсутствующем отчестве;
4. близкие написания (расстояние Левенштейна ≤ 2 по фамилии **или** ≤ 1 по имени,
   но не по обоим сразу) при совпадающем годе рождения и нормализованном регионе;
5. проверка уже существующих merge;
6. контроль: пара, встретившаяся в **одной категории одного турнира**, из кандидатов
   исключается — это доказательство разных людей.

Регион нормализован по правилу skill: `обл.` = `обл` = `область`. Различие только в
сокращении конфликтом не считается.

## A. Опечатки в написании ФИО

Год рождения и регион совпадают, различие — одна-две буквы. Самая массовая категория:
почти всегда OCR/набор протокола, а не два человека. Типичный признак — вместе с ФИО
«плывёт» и фамилия тренера (`Кацюба` / `Кащуба`, `Шемякин` / `Щемякин`,
`Мащенко` / `Машенко`, `Шолох` / `Шилох`): значит, вся строка распознана иначе.
