# Разряд и последняя весовая в списке спортсменов

- «Разряд» берётся из последнего опубликованного результата, где разряд указан; если в результатах разряд нигде не указан, используется `athletes.sport_rank_id`.
- «Последняя весовая» берётся из самого позднего опубликованного старта спортсмена.
- Рядом с весовой категорией показывается год этого старта.
- Сортировка разряда использует `sport_ranks.sort_order`.
- Сортировка весовой категории использует `weight_class_kg`; открытая категория сортируется после закрытой категории с тем же числом.
