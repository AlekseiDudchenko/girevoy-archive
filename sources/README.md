# Оригиналы протоколов

В этой директории хранятся оригинальные файлы протоколов соревнований, на основании
которых формируются данные `data/*.json`.

Структура:

- `sources/<год>/` — PDF/XLS/XLSX, опубликованные организатором или федерацией;
- `sources/manifest.json` — размер и SHA-256 каждого архивного файла.

## Правила

1. Оригинальный бинарный файл не редактируется после добавления в архив.
2. Для нового протокола сначала сохраняется первоисточник в `sources/<год>/`, затем
   из него формируются или обновляются `data/*.json`.
3. В `data/*.json` поле `source.filename` по возможности должно совпадать с именем
   архивного файла.
4. Внешний официальный URL (`source_url`) сохраняется как provenance, но архивная
   копия в репозитории нужна на случай удаления или переноса файла на сайте источника.
5. Если источник опубликовал новую редакцию того же протокола, старую копию не
   перезаписывать: новую редакцию сохранить отдельным файлом и зафиксировать различие.

`manifest.json` позволяет проверить, что сохранённый первоисточник не изменился.

Для первоначального наполнения используется workflow
`.github/workflows/archive-source-protocols.yml`, который скачивает доступные официальные
протоколы и пересобирает manifest.

Оригиналы за 2019 и 2020 добавлены вручную и в список воркфлоу не внесены намеренно.
Эти копии уже сверены с данными, а воркфлоу перезаписывает файл безусловно. Если источник
опубликует новую редакцию, существующий файл не перезаписывать и URL не добавлять в этот
workflow в текущем виде: новую редакцию сохранить отдельным файлом, обновить provenance
осознанным изменением и зафиксировать различие хешей (правило 5).
